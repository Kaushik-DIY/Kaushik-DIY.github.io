Precision Landing with PPO: LunarLander-v2

Training a continuous control agent to land a spacecraft between two flags using Proximal Policy Optimization

PPOCleanRLGymnasiumContinuous ControlPyTorch

Agent Demo

PPO agent executing a stable landing between the two flags - throttling main and side engines to control descent

Overview

Trained a PPO agent using a CleanRL-style implementation in PyTorch to solve the LunarLander-v2 environment from Gymnasium. The agent controls a lander with three engine actuators - main engine and two side boosters - and must learn to descend smoothly and land precisely between two flags on uneven terrain, without crashing or running out of fuel.

Problem and Approach

LunarLander-v2 is a classic benchmark for continuous control with discrete actions. The challenge is that the environment rewards precision: landing too fast, touching legs outside the pad, or firing engines unnecessarily all incur penalties. The agent must learn a nuanced policy that balances fuel efficiency against stability - which requires understanding the physics of thrust and gravity simultaneously.

PPO is well-suited here because the policy must be updated carefully to avoid catastrophic forgetting of stable landing behavior discovered earlier in training. The clipped surrogate objective prevents large, destabilizing updates to the policy.

Technical Implementation

Algorithm: PPO (CleanRL-style)

Implemented using CleanRL's clean single-file PPO in PyTorch. The policy network maps the 8-dimensional state vector to action logits, updated via the clipped surrogate objective with generalized advantage estimation (GAE). Entropy bonus maintains sufficient exploration throughout training.

Environment Details

  • Environment: LunarLander-v2 (Gymnasium)
  • Observation: 8-dimensional state vector (position, velocity, angle, angular velocity, leg contact flags)
  • Action space: 4 discrete actions (do nothing, fire left engine, fire main engine, fire right engine)
  • Reward: +100/+10 for landing legs, -100 for crash, -0.3 per frame main engine fired, -0.03 side engine
  • Solved threshold: mean reward above 200 over 100 episodes

Key Learnings

LunarLander-v2 taught the importance of reward shaping awareness. The fuel penalty fundamentally changes the learned policy - an agent trained without it learns aggressive, high-thrust landings, while the penalized version develops a more fuel-efficient glide approach. Understanding how reward structure shapes behavior, not just outcome, is a key insight for designing RL systems in real applications.

GAE's lambda parameter also had a significant effect: lower lambda produced lower-variance but higher-bias advantage estimates, leading to faster convergence but sometimes suboptimal final policies. Tuning this tradeoff was a meaningful practical exercise.

Real-World Relevance

  • Autonomous spacecraft or drone precision landing under fuel constraints
  • Any control task where the agent must balance efficiency and stability simultaneously
  • Benchmark for testing policy gradient methods on physics-based control problems
