REINFORCE Policy Gradient Agent for Pixelcopter

Implementing vanilla policy gradient from scratch to train a visual control agent on raw pixel input

Overview

Implemented the REINFORCE policy gradient algorithm from scratch in PyTorch to train an agent on Pixelcopter-PLE-v0 - a visual control task where the agent sees only raw pixel input and must learn to toggle engine thrust to fly a helicopter through an endless series of gaps. The policy network maps pixel observations directly to action probabilities, with no hand-crafted features or domain knowledge.

Problem and Approach

Pixelcopter is a deceptively hard visual control problem. The observation is a small pixel grid (48x48) and the agent must learn: what the helicopter looks like, what constitutes a gap, how to estimate distance to walls, and how to control altitude through discrete thrust toggles - all from reward signal alone.

REINFORCE, as the simplest policy gradient method, has high variance in its gradient estimates because it uses full Monte Carlo returns. This makes it harder to train stable policies on visual tasks than actor-critic methods, but also makes it an important baseline for understanding why variance reduction techniques (baselines, advantage estimation) matter in practice.

Technical Implementation

Algorithm: REINFORCE (Vanilla Policy Gradient)

The policy is a convolutional neural network mapping pixel observations to action logits. At each episode, a full trajectory is collected and the policy is updated by maximizing the log-probability of taken actions weighted by their discounted returns. No value function or advantage estimation is used - purely Monte Carlo returns with a reward-to-go formulation.

Environment Details

  • Environment: Pixelcopter-PLE-v0 (PyGame Learning Environment)
  • Observation: Raw pixel grid (48x48 RGB) - no engineered features
  • Action space: 2 discrete actions (thrust on, thrust off)
  • Reward: +1 per gap passed, -1 for collision
  • Challenge: High-variance gradient estimates from Monte Carlo returns on pixel input

Key Learnings

The high standard deviation in results (±31.20) is itself an important finding. It demonstrates concretely why REINFORCE struggles on visual tasks: full Monte Carlo returns create noisy gradient estimates that cause significant performance variation between runs. This makes a compelling practical argument for variance reduction techniques - baselines, advantage estimation, and actor-critic architectures are not just theoretical improvements, they are necessary engineering choices for stable visual RL.

Working directly with pixel observations also highlighted the sensitivity of convolutional policies to input normalization and architecture choices in ways that are invisible when using pre-processed state vectors.

Real-World Relevance

  • Understanding the limitations of vanilla policy gradient as motivation for modern actor-critic methods
  • Visual control tasks where feature engineering is impractical or impossible
  • Baseline comparison for evaluating variance reduction techniques in policy gradient research
