Survival Under Pressure: APPO Agent in VizDoom Health Gathering

Training a first-person 3D agent to survive indefinitely by learning to seek and collect health under time pressure

APPOSample-FactoryVizDoomFirst-Person 3DSurvival RL

Agent Demo

APPO agent navigating the doom_health_gathering_supreme environment, actively seeking health packs to stay alive

Overview

Trained an APPO (Asynchronous Proximal Policy Optimization) agent using Sample-Factory 2.0 to survive indefinitely in the doom_health_gathering_supreme environment from VizDoom. The agent operates from a first-person 3D perspective and must continuously seek and collect health packs to avoid dying with no map, no indicators, and no explicit guidance on where health is located.

Problem and Approach

Unlike tabular or 2D environments, this task demands spatial reasoning from raw visual input in a 3D first-person setting. The agent receives only its camera view and must learn navigation, target identification, and collection behavior purely from reward signals tied to survival duration.

Standard synchronous PPO becomes a bottleneck at scale with high-resolution environments. Sample-Factory's APPO decouples environment interaction from policy updates using an asynchronous actor-learner architecture, enabling significantly higher environment throughput without sacrificing sample efficiency.

Technical Implementation

Algorithm: APPO via Sample-Factory 2.0

APPO uses the same clipped surrogate objective as PPO but separates environment workers, inference, and learning into asynchronous processes. This allows the learner to update continuously while rollout workers collect experience in parallel, drastically increasing training throughput on complex 3D environments.

Environment Details

  • Environment: doom_health_gathering_supreme (VizDoom)
  • Observation: Raw first-person camera image (RGB pixels)
  • Action space: Discrete movement and turning commands
  • Reward: +1 per timestep alive, episode ends on death
  • Challenge: Health packs spawn randomly, agent must actively explore to survive

Key Learnings

This project highlighted the practical gap between training efficiency in simple environments and real 3D visual tasks. APPO's asynchronous design is not just a performance optimization, it becomes a fundamental requirement when environment steps are expensive and policy updates cannot stall waiting for synchronous rollouts.

Working with raw pixel observations also reinforced the importance of convolutional architectures and frame stacking for giving the agent temporal context, a single frame is insufficient to infer movement direction or velocity in a 3D setting.

Real-World Relevance

  • Navigation in GPS-denied or visually complex 3D environments
  • Autonomous robot behavior in unstructured indoor spaces from camera input only
  • Any first-person perception task where the agent must learn spatial reasoning from pixels
